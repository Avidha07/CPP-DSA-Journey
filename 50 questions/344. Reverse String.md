# 344. Reverse String

## Problem Statement

Given an array of characters `s`, reverse the string in-place.

You must use only constant extra memory.

---

# Example

## Example 1
Input:
```cpp
s = ['h','e','l','l','o']
```

Output:
```cpp
['o','l','l','e','h']
```

---

## Example 2

Input:
```cpp
s = ['H','a','n','n','a','h']
```

Output:
```cpp
['h','a','n','n','a','H']
```

---

# Approaches

# 1. Built-in Function Approach

## Code

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
       reverse(s.begin(), s.end());
    }
};
```

## Time Complexity
O(n)

## Space Complexity
O(1)

## Explanation
The STL `reverse()` function reverses the array internally using swapping.

---

# 2. Brute Force Approach

## Code

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {

        int n = s.size();

        vector<char> v;

        for(int i = n - 1; i >= 0; i--)
        {
            v.push_back(s[i]);
        }

        for(int i = 0; i < n; i++)
        {
            s[i] = v[i];
        }
    }
};
```

## Time Complexity
O(n)

## Space Complexity
O(n)

## Explanation
We create another vector and store elements in reverse order, then copy them back to the original array.

---

# 3. Optimal Approach — Two Pointer

## Code

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {

        int i = 0;
        int j = s.size() - 1;

        while(i < j)
        {
            swap(s[i], s[j]);
            i++;
            j--;
        }
    }
};
```

## Time Complexity
O(n)

## Space Complexity
O(1)

## Explanation
Two pointers are used:
- One starts from the beginning
- One starts from the end

Both characters are swapped until pointers cross each other.

This is the most optimized approach.

---

# 4. Recursive Approach

## Code

```cpp
class Solution {
public:

    void solve(vector<char>& s, int left, int right)
    {
        if(left >= right)
        return;

        swap(s[left], s[right]);

        solve(s, left + 1, right - 1);
    }

    void reverseString(vector<char>& s) {
        solve(s, 0, s.size() - 1);
    }
};
```

## Time Complexity
O(n)

## Space Complexity
O(n)

## Explanation
Recursion swaps the first and last characters repeatedly.

Extra space is used because of the recursive call stack.
