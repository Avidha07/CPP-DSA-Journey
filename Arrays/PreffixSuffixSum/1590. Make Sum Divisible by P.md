# LeetCode 1590 — Make Sum Divisible by P

## Intuition

We need to remove the **smallest subarray** such that the sum of the remaining elements is divisible by `p`.

First, calculate the remainder of the total sum:

```text
target = totalSum % p
```

If `target == 0`, the total sum is already divisible by `p`, so the answer is `0`.

Otherwise, we need to find the smallest subarray whose sum has remainder `target` when divided by `p`.

To find this subarray efficiently, we use **prefix sum + modulo + hashmap**.

---

## Approach

### 1. Calculate Total Sum

Calculate the sum of all elements and find its remainder:

```cpp
target = totalSum % p;
```

This `target` tells us what remainder the removed subarray must have.

### 2. Use Prefix Sum

While traversing the array, calculate:

```cpp
currSum = (currSum + nums[i]) % p;
```

We only store the remainder because we only care about divisibility by `p`.

### 3. Find the Required Remainder

Suppose the current prefix remainder is `currSum`.

We need a previous prefix remainder such that:

```text
(currSum - previousRemainder) % p = target
```

Therefore:

```cpp
rem = (currSum - target + p) % p;
```

If this remainder already exists in the hashmap, we found a subarray that can be removed.

### 4. Store Index in HashMap

The hashmap stores:

```text
remainder → index
```

We initialize:

```cpp
mp[0] = -1;
```

This handles subarrays starting from index `0`.

For every valid subarray, calculate:

```cpp
length = i - mp[rem];
```

and keep the minimum length.

---

## Important Trick

```cpp
rem = (currSum - target + p) % p;
```

The `+ p` prevents the value from becoming negative before applying `% p`.

For example:

```text
currSum = 2
target = 5
p = 6

(2 - 5 + 6) % 6
= 3 % 6
= 3
```

---

## Example

```text
nums = [3, 1, 4, 2]
p = 6
```

### Step 1: Total Sum

```text
3 + 1 + 4 + 2 = 10
```

```text
10 % 6 = 4
```

So:

```text
target = 4
```

We need to remove a subarray whose sum `% 6` is `4`.

### Step 2: Find the Subarray

The subarray:

```text
[4]
```

has:

```text
4 % 6 = 4
```

Remove it:

```text
[3, 1, 2]
```

Remaining sum:

```text
3 + 1 + 2 = 6
```

```text
6 % 6 = 0
```

The removed subarray has length:

```text
1
```

Therefore:

```text
Answer = 1
```

## Complexity

* **Time Complexity:** `O(n)`

  * We traverse the array once.
  * Hashmap lookup and insertion take `O(1)` average time.

* **Space Complexity:** `O(n)`

  * The hashmap can store up to `n` prefix remainders.

---

## Key Takeaway

```text
Total Sum % p
       ↓
Find target remainder
       ↓
Prefix Sum + Modulo
       ↓
HashMap of remainder → index
       ↓
Find shortest subarray
```

### Pattern to Remember

**"Find the smallest subarray having a required remainder" → Prefix Sum + Modulo + HashMap**
