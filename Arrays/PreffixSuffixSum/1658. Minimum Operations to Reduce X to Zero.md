1658. Minimum Operations to Reduce X to Zero

Problem

Given an integer array nums and an integer x, in one operation we can remove either the leftmost or the rightmost element and subtract its value from x.

Return the minimum number of operations required to reduce x to exactly 0. If it is impossible, return -1.

Key Observation

Instead of thinking about the elements we remove, think about the elements we keep.

Let:

totalSum = sum of all elements

If the elements removed have sum x, then the remaining elements have sum:

remainingSum = totalSum - x

So the problem becomes:

Find the longest contiguous subarray whose sum is totalSum - x.

Why the longest subarray?

If we keep the maximum number of elements, we remove the minimum number of elements.

Therefore:

minimum operations = n - longest subarray length

Example

nums = [1, 1, 4, 2, 3]
x = 5

First calculate:

totalSum = 1 + 1 + 4 + 2 + 3
         = 11

target = totalSum - x
       = 11 - 5
       = 6

Now find the longest subarray with sum 6.

[1, 1, 4] = 6

Its length is 3.

Therefore:

minimum operations = n - maxLen
                   = 5 - 3
                   = 2

We remove:

2 + 3 = 5

So the answer is 2.

Sliding Window

All nums[i] are positive.

This is important because with positive numbers:

Increasing the right pointer increases the window sum.

Increasing the left pointer decreases the window sum.

Therefore, we can use a sliding window.

Algorithm

Calculate totalSum.

Calculate:

target = totalSum - x

If target < 0, return -1.

Use two pointers i and j to maintain a sliding window.

Add nums[j] to the current sum.

If the sum becomes greater than target, move i forward and remove elements.

Whenever:

sum == target

update the maximum window length.

Return:

n - maxLen

Dry Run

Consider:

nums = [3, 2, 20, 1, 1, 3]
x = 10

Step 1: Total Sum

totalSum = 3 + 2 + 20 + 1 + 1 + 3
         = 30

Therefore:

target = 30 - 10
       = 20

We need the longest subarray with sum 20.

Sliding Window

Start:

i = 0
j = 0
sum = 0

Add 3:

window = [3]
sum = 3

Add 2:

window = [3, 2]
sum = 5

Add 20:

window = [3, 2, 20]
sum = 25

25 > 20, so shrink from the left.

Remove 3:

window = [2, 20]
sum = 22

Still greater than 20.

Remove 2:

window = [20]
sum = 20

Now:

sum == target

So:

maxLen = 1

Continue.

Add 1:

window = [20, 1]
sum = 21

Shrink:

window = [1]
sum = 1

Continue with the remaining elements.

Eventually, the longest valid subarray is:

[20]

with length 1.

Therefore:

operations = 6 - 1
           = 5

Answer:

5

Important Edge Cases

1. target < 0

totalSum < x

Even removing all elements cannot reduce x to zero.

Return:

-1

2. target == 0

This means:

totalSum == x

We need to remove every element.

Therefore:

answer = n

There is no non-empty subarray that needs to be kept.

3. No subarray has sum target

Then there is no possible combination of left/right removals that gives exactly x.

Return:

-1

C++ Solution

class Solution {
public:
    int minOperations(vector<int>& nums, int x) {

        int n = nums.size();

        // Calculate total sum
        int totalSum = 0;

        for (int num : nums) {
            totalSum += num;
        }

        // We need to keep a subarray with this sum
        int target = totalSum - x;

        // Impossible to remove elements whose sum is x
        if (target < 0) {
            return -1;
        }

        int i = 0;
        int sum = 0;

        // If target == 0, we need to remove all elements
        int maxLen = (target == 0 ? 0 : -1);

        for (int j = 0; j < n; j++) {

            sum += nums[j];

            // Shrink window if sum becomes too large
            while (i <= j && sum > target) {
                sum -= nums[i];
                i++;
            }

            // We found a valid subarray
            if (sum == target) {
                maxLen = max(maxLen, j - i + 1);
            }
        }

        // No valid subarray found
        if (maxLen == -1) {
            return -1;
        }

        // Remove everything outside the longest valid subarray
        return n - maxLen;
    }
};

Complexity

Time

O(n)

Each element is added to the window once and removed at most once.

Space

O(1)

Only a few variables are used.

The Main Trick

Remember this transformation:

Original:
Remove elements from left/right with sum = x

        ↓

Transformation:
Keep a subarray with sum = totalSum - x

        ↓

Goal:
Find the LONGEST such subarray

        ↓

Answer:
n - longestSubarrayLength

One-line intuition

Convert "minimum elements to remove" into "maximum elements to keep."
